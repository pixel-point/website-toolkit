A few useful details

Before you begin

Do I need to install everything myself?

Your assistant handles supported installation from the setup prompt. You may need to approve an operating-system prompt or complete a sign-in. The setup currently targets local Codex and Claude Code on macOS/Linux; Windows needs guided setup.

What accounts and access do I need?

You need access to the private plugin repository and the relevant your website projects in Sanity, SiteOS, Prime and Vercel when used. Creating a new account does not grant access to the team's existing projects. The assistant will tell you if an invitation is missing.

What if the assistant asks me to start a new chat?

Newly installed plugins may need a reload or new session. Copy the resume prompt the assistant provides. It will check the completed steps and continue without reinstalling working tools.

Will setup change the live website or run paid checks?

No. Setup installs tools and verifies access. Publishing pages, deploying code and running paid research are separate actions with a clear requested scope.

How do the tools stay up to date?

GitHub, SiteOS, Prime, Sanity and Vercel remain independently installed. Ask: “Check and update my website tools, then verify the connections.” The assistant checks for conflicts and explains any required reload.
